# Ejecutables listos para usar

Aquí encontrarás el programa listo para ejecutar. **No es necesario instalar nada.**

## GeneradorQR.exe — Generador de códigos QR para Windows

### Cómo usarlo

1. Haz doble clic en `GeneradorQR.exe`
2. Escribe la dirección, URL o texto que quieres convertir en QR
3. Presiona **Generar QR**
4. Elige dónde guardar la imagen

El archivo se guarda como `.png`, que puedes imprimir, insertar en un documento de Word o compartir por correo.

### Advertencia de seguridad de Windows

Es posible que Windows muestre un mensaje como *"Windows protegió tu PC"*. Esto ocurre porque el ejecutable no tiene una firma digital de pago, no porque sea peligroso. Para continuar:

1. Haz clic en **"Más información"**
2. Luego en **"Ejecutar de todas formas"**

El código fuente completo de esta herramienta está disponible en la carpeta `dotnet/` para quien quiera auditarlo.
